# Pinned hard, and the pins are not cosmetic.
#
# This machine is an Intel Mac (x86_64). PyTorch stopped publishing macOS x86_64
# wheels after 2.2.2, so 2.2.2 is a hard ceiling, not a preference. Everything
# below is pinned to what torch 2.2.2 can actually work with:
#
#   numpy<2            torch 2.2.2 is compiled against the NumPy 1.x C API.
#                      With numpy 2.x it imports but cannot initialise NumPy.
#   transformers 4.x   transformers 5.x requires torch>=2.5 and silently
#                      disables PyTorch on 2.2.2 ("Models won't be available").
#   huggingface-hub<1  transformers 4.44 does not support the 1.x hub API.
#
# Unpinning any of these produces an install that exits 0 and then cannot load
# a model. See INTEGRATION_CONTRACT.md §6 and notes.md, Month 3 Day 1.

torch==2.2.2
numpy==1.26.4
transformers==4.44.2
tokenizers==0.19.1
huggingface-hub==0.24.6
sentence-transformers==3.0.1
